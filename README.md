# ZoomEGE

Веб-тренажёр для подготовки к ЕГЭ по русскому языку. Пользователь выбирает тему и подтему, решает задания, а приложение сохраняет результат и показывает статистику в профиле.

![Flask](https://img.shields.io/badge/Flask-2.2-000000?logo=flask&logoColor=white)
![SQLite](https://img.shields.io/badge/SQLite-3-003B57?logo=sqlite&logoColor=white)

> Учебный проект 2022–2023 годов. База содержит демонстрационный набор из 3 тем, 13 подтем и 441 задания.

## Возможности

- регистрация и авторизация пользователей;
- выбор темы и подтемы;
- задания с выбором буквы или варианта ответа;
- продолжение незавершённого тестирования;
- история попыток и статистика за текущий месяц;
- создание тем, подтем и заданий администратором;
- управление данными через Flask-Admin.

## Запуск

1. Клонируйте репозиторий и перейдите в его каталог.
2. Создайте и активируйте виртуальное окружение:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. Задайте секретный ключ и, при необходимости, адрес администратора:

   ```powershell
   $env:ZOOMEGE_SECRET_KEY = "replace-with-a-random-secret"
   $env:ZOOMEGE_ADMIN_EMAIL = "admin@example.com"
   ```

5. Запустите приложение:

   ```powershell
   python app.py
   ```

6. Откройте [http://127.0.0.1:5002](http://127.0.0.1:5002).

Чтобы открыть инструменты администратора, зарегистрируйтесь с адресом, указанным в `ZOOMEGE_ADMIN_EMAIL`. Остальные параметры запуска перечислены в [`.env.example`](.env.example).

## База данных

В репозитории хранится обезличенный шаблон `db/rus.example.db`: в нём есть учебные материалы, но нет пользователей и связанной с ними истории. При первом запуске приложение автоматически создаёт из шаблона рабочий файл `db/rus.db`. Рабочая база добавлена в `.gitignore` и не должна попадать в репозиторий.

Чтобы вернуться к исходным демонстрационным данным, остановите приложение и удалите `db/rus.db`. При следующем запуске файл будет создан заново.

## Ограничения

Проект создан в учебных целях и рассчитан на локальный запуск. Перед размещением в интернете ему потребуются полноценная защита изменяющих API-запросов от CSRF, миграции базы данных и дополнительная проверка пользовательского ввода. Проект не связан с ФИПИ или Рособрнадзором.
